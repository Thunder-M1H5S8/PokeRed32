# PokeRed32
A custom handheld gaming device built using an ESP32 DevKit V1 capable of running Pokemon Red.
# ESP32 Pokemon Handheld

## Hardware

- ESP32 DevKit V1
- 3.5" SPI TFT Display
- Micro SD Card Module
- Speaker + Amplifier
- RTC Module
- Rotary Encoder
- Push Buttons
